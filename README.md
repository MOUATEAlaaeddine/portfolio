# Alaa Eddine Mouate — Portfolio

This is my personal portfolio. I'm a Software & AI Engineer and a master's student in Information Systems Engineering (FSSM, Marrakech).

It shows who I am, my journey, my projects, my tech stack and how to contact me. It's available in English, French and Arabic.

Built with React, Vite and GSAP. Hosted on Vercel.

## Run it locally

```bash
git clone https://github.com/MOUATEAlaaeddine/portfolio.git
cd portfolio
npm install
npm run dev
```

Then open http://localhost:5173.
